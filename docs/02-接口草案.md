## 2. 鉴权与安全

- REST 仅监听 `127.0.0.1`（`ZHILIAN_HOST`）；除 `/v1/health` 外均需 `Authorization: Bearer <ZHILIAN_API_TOKEN>`。
- `ZHILIAN_API_TOKEN` 默认 `change-me`，部署时必须修改；支持配置文件/env。
- 登录/验证相关接口（`/v1/session/login*`、`/v1/verification*`）额外约束：
  - 仅 loopback；单活跃 loginId；TTL 10 分钟；
  - 二维码/验证码截图仅内存或临时文件（600 权限，TTL 删除），不写长期日志；
  - 响应中的 `qr.pngBase64` / `screenshotBase64` / `mainBase64` 不回显到日志；调用方自行负责展示与销毁。
- 凭据：手机号从 `ZHILIAN_PHONE` 或 600 权限配置文件读取；不硬编码、不写日志、不写入响应（只返回掩码）。
- 单实例：同一 `profileDir` 只允许一个进程（`.zhilian-client.lock`，pid 存活检测）。
- 日志脱敏：手机号、验证码、cookie、token、EdgeOne token、`EO-Bot-Captcha-Token`、二维码内容（日志中截断/哈希）。
- 只读：不提供投递/沟通/简历/收藏接口。

### 3.3 meta 字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| schemaVersion | `"1.0"` | 是 | 响应包 schema 版本 |
| requestId | string | 是 | 贯穿日志的请求 ID |
| timestamp | ISO8601 | 是 | 服务端时间（含时区） |
| tookMs | int ≥0 | 是 | 处理耗时 |
| cached | boolean | 是 | 是否命中缓存 |
| mode | `logged_in` / `anonymous` | 是 | 本次调用所处模式（匿名限制见 §5.5） |
| pagination | object | 否 | 分页操作返回 |
| warnings | string[] | 是 | 非致命告警（`anonymous_limited`、`truncated`、会话将过期、EdgeOne token 将过期等） |
| upstream | object | 否 | 上游调用信息（baseUrl/latencyMs/requestKind） |

`requestKind` 枚举：`ssr_document`（页面内 fetch SSR HTML）、`fe_api`（fe-api JSON）、`browser_nav`（真实页面导航，仅登录/人机验证用）、`none`（纯缓存）。

## 5. 分页、queryId、refresh、匿名模式、限频、缓存

### 5.1 分页与 queryId

- 搜索/翻页以 `queryId` 为锚点：`q_<yyyymmdd>_<rand>`。
- 服务端在 SQLite `queries` 保存搜索条件（keyword/cityCode(jl)/order/pageSize/已抓页/hasMore/匿名标记），默认 TTL 24h。
- `search.jobs` 返回 `queryId`；`jobs.list` / `companies.list` 使用该 queryId。
- `page` 从 1 开始，对应上游 `p` 参数；`pageSize` v1 固定 20（上游固定 20，见实测）。
- `hasMore` 取上游 state 的 `hasMore`；`pagesAvailable` 在登录模式下由 `hasMore` 与配置 `MAX_PAGES` 推导（具体上限待登录后实测）。
- `companies.list` 的 `total` 是**去重后公司数**，不是职位数。

### 5.2 refresh 语义

- 读接口默认走 TTL 缓存；`refresh=true` 强制请求上游并写回缓存。
- 搜索：`refresh=true` 重建 queryId（新查询）；`jobs.list` 的 `refresh=true` 只刷新该页。
- 详情：`refresh=true` 绕过对应详情缓存。
- `meta.cached=true` 表示本次结果来自缓存；强制刷新时 `cached=false`。

### 5.3 重试与限频

- 可重试：`AUTH_REQUIRED`、`HUMAN_VERIFICATION_REQUIRED`、`HUMAN_VERIFICATION_FAILED`、`CAPTCHA_*`、`SMS_CODE_INVALID`、`SMS_RATE_LIMITED`、`RATE_LIMITED`、`TIMEOUT`、`UPSTREAM_UNAVAILABLE`、`SERVICE_UNAVAILABLE`。
- 客户端建议指数退避（1s/2s/4s，最多 3 次）；`RATE_LIMITED` 使用 `details.retryAfterMs`。
- 服务端默认限频：
  - 上游请求 **15 次/分**（令牌桶，容量 3）；
  - 单并发，同一时刻只允许 1 个上游请求；
  - 页间延迟 2.5–4s 抖动；
  - 单次任务最多 5 页（`search.jobs.pages` / `fetchPages` 上限 5）；
  - 连续风控/EdgeOne 失败 → 冷却 60s + 重试 1 次；仍失败返回 `UPSTREAM_BLOCKED`，`status.risk.cooldownUntil` 可见。
- 禁止对同一账号并行发起多个搜索/详情任务。

### 5.4 缓存 TTL（默认，可配）

| 数据 | TTL |
| --- | --- |
| queries | 24h |
| jobs（职位列表行） | 2h |
| job_details | 12h |
| companies（公司摘要） | 7d |
| company_details | 7d |
| company_jobs | 2h |

### 5.5 匿名模式与登录模式

| 模式 | 判定 | 能力 | 说明 |
| --- | --- | --- | --- |
| `logged_in` | `checkToken.data === true` | 全部能力（翻页上限待实测） | 推荐 |
| `anonymous` | 未登录且 `ZHILIAN_ANONYMOUS=true`（默认 true） | 搜索仅第 1 页 20 条；职位/公司详情可读（薪资展示以页面为准，state 有真值）；`jobs.list page>1` → `ANONYMOUS_LIMITED` | 降级模式 |

- `meta.mode` 明确标识当前模式；`status.mode` 同义。
- 匿名模式下 `search.jobs` 的 `meta.warnings` 追加 `anonymous_limited`。
- 需要登录但当前为匿名 → `LOGIN_REQUIRED`（retryable=true，提示先登录）。

## 7. 操作规范

> 所有操作返回 envelope；以下只列 `data`。CLI/MCP 与 REST 同 schema。

### 7.1 health.get

- 鉴权：无。
- 只读、幂等。
- 请求：无。
- 响应：见 §6.7。
- 用途：进程/浏览器存活、登录/验证概览。

### 7.2 status.get

- 鉴权：Bearer。
- 只读、幂等。
- 请求：无。
- 响应：见 §6.7。
- 说明：登录态 + 模式 + 会话 + EdgeOne token + 风控冷却 + 请求计数 + 缓存；无 quota。
- 实现建议：`checkToken` 单次轻量请求 + cookies 本地读取；`ZHILIAN_CHECK_TOKEN_ON_STATUS=false` 时纯本地快照。

### 7.3 session.login.start

- 鉴权：Bearer。
- 副作用：打开/复用浏览器；可能发送短信。
- 请求：

```json
{ "mode": "app-qr", "phone": "15600000000", "refresh": false }
```

`phone` 可选；缺省用 `ZHILIAN_PHONE`。`mode` 可选：缺省按配置选择（`ZHILIAN_HEADLESS=true` → `app-qr`，否则 `app-qr` 仍可；`sms` 需 headful）。

- 响应：`LoginSession`（见 §6.8）。
- 行为：
  - 若当前已登录：直接返回 `state=logged_in`，不打开浏览器（幂等，便于调用方重试）；
  - `app-qr`：`GET /v4/appScan/init?scene=10000060` 取得二维码并返回 Base64；后台开始轮询 `/v4/appScan/login`；
  - `sms`：切到验证码面板 → 填手机号 → 点击发送 → 若出现 NC/极验则返回 `state=awaiting_captcha`（正常状态，非错误，带验证挑战）；否则 `state=awaiting_sms_code`。
- 错误：`LOGIN_IN_PROGRESS`、`SMS_RATE_LIMITED`、`HEADFUL_REQUIRED`（sms 模式且无 DISPLAY）。
- 说明：同一时刻只允许一个 loginId；TTL 10 分钟；`app-qr` 二维码约 5 分钟有效，过期自动重新 init。

### 7.4 session.login.get

- 鉴权：Bearer。
- 请求：路径 `loginId`。
- 响应：`LoginSession`；`app-qr` 模式可返回刷新后的 `qr.pngBase64`（二维码过期时自动重新生成）。
- 错误：`LOGIN_EXPIRED`。

### 7.5 session.login.sms

- 鉴权：Bearer。
- 请求：

```json
{ "code": "123456" }
```

- 响应：`LoginSession`；成功 `state=logged_in`。
- 错误：`SMS_CODE_INVALID`、`HUMAN_VERIFICATION_REQUIRED`（登录时再次出现验证码，`details.verification`）、`SMS_RATE_LIMITED`、`LOGIN_EXPIRED`。
- 说明：登录成功后保存 profile/storage state；不返回 cookie/token。

### 7.6 session.login.cancel

- 鉴权：Bearer。
- 请求：路径 `loginId`。
- 响应：`{ "loginId": "...", "state": "cancelled" }`。
- 说明：关闭/释放 loginId；不影响已登录会话。

### 7.7 verification.get

- 鉴权：Bearer。
- 请求：无。
- 响应：

```json
{ "pending": true, "kind": "edgeone", "challenge": { "...": "VerificationChallenge" } }
```

无待处理时：

```json
{ "pending": false, "kind": null, "challenge": null }
```

- 说明：查询当前浏览器会话中挂起的人机验证（EdgeOne 页面挑战、登录 NC/极验）。

### 7.8 verification.solve

- 鉴权：Bearer。
- 请求（EdgeOne 自动）：

```json
{ "kind": "edgeone", "auto": true }
```

- 请求（EdgeOne 点击，坐标 0–1 相对截图）：

```json
{ "kind": "edgeone", "points": [{ "x": 0.12, "y": 0.28 }] }
```

- 请求（极验点选/滑块）：

```json
{ "kind": "geetest", "points": [{ "x": 0.683, "y": 0.625 }, { "x": 0.173, "y": 0.541 }] }
```

```json
{ "kind": "geetest", "offsetRatio": 0.63 }
```

- 响应：

```json
{ "solved": true, "verification": { "pending": false, "kind": null }, "message": "verification passed" }
```

- 错误：`HUMAN_VERIFICATION_FAILED`（`details.verification` 为新挑战）、`HUMAN_VERIFICATION_REQUIRED`（挑战过期需重新获取）。
- 说明：`auto=true` 时服务端尝试在 iframe 内点击复选框（实测可行，`ZHILIAN_EDGE_AUTO` 默认 false 时也可显式调用）；失败则返回新挑战。

### 7.9 search.jobs

- 鉴权：Bearer。
- 只读、幂等（同一条件可重复）。
- 请求：

```json
{ "keyword": "外贸", "cityCode": "565", "page": 1, "pages": 1, "order": 4, "refresh": false }
```

| 字段 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| keyword | 是 | — | 职位关键词 |
| cityCode | 否 | 配置默认（565） | 城市码（`jl`）；`489`=全国 |
| page | 否 | 1 | 起始页（上游 `p`） |
| pages | 否 | 1 | 本次抓取页数，1–5 |
| order | 否 | 4 | 排序（4=最新） |
| refresh | 否 | false | 绕过缓存 |

- 响应：

```json
{
  "query": { "queryId": "q_...", "keyword": "外贸", "cityCode": "565", "cityName": "石家庄", "order": 4, "pageSize": 20, "pagesFetched": 1, "hasMore": false, "count": 20, "anonymous": false, "fetchedAt": "..." },
  "jobs": [ "JobSummary..." ],
  "companies": [ "CompanySummary..." ],
  "pagination": { "page": 1, "pageSize": 20, "total": 20, "hasMore": false, "pagesFetched": 1, "pagesAvailable": 1 }
}
```

- 行为：页面内 fetch `/jobs/?kw=&jl=&p=&order=` SSR HTML → 解析 `__INITIAL_STATE__` → 映射 `positionList`；按页抓取（`pages` 页，页间延迟）；写入 queries/jobs/companies 缓存；`companies` 为已抓页去重结果。
- 匿名模式：`p>1` 或 `pages>1` 时仅第 1 页有效，`meta.warnings=["anonymous_limited"]`；超出 → `ANONYMOUS_LIMITED`。
- 错误：`AUTH_REQUIRED`/`LOGIN_REQUIRED`、`HUMAN_VERIFICATION_REQUIRED`、`UPSTREAM_BLOCKED`、`UPSTREAM_CHANGED`、`TIMEOUT`、`RATE_LIMITED`。

### 7.10 jobs.list

- 鉴权：Bearer。
- 请求：`queryId`（必填）、`page`（默认 1）、`refresh`。

- 错误：`QUERY_EXPIRED`、`ANONYMOUS_LIMITED`、`AUTH_REQUIRED`、`HUMAN_VERIFICATION_REQUIRED`、`UPSTREAM_BLOCKED`。

### 7.11 jobs.detail

- 鉴权：Bearer。
- 请求：路径 `positionNumber`；query `refresh` 可选。

```text

```

- 响应：`JobDetail`（见 §6.2）。
- 行为（三级回退，见 PRD §4.4）：
  1. 缓存命中（12h）；
  2. 搜索结果内嵌 `jobDetailData`（若来自 queryId 缓存）；
  3. `GET https://fe-api.zhaopin.com/c/i/jobs/position-detailv3?number=<positionNumber>&identity=0`；
  4. 仍失败 → `/jobdetail/<positionNumber>.htm` 页面 SSR（可能触发 EdgeOne → `HUMAN_VERIFICATION_REQUIRED`）。
- 错误：`NOT_FOUND`、`HUMAN_VERIFICATION_REQUIRED`、`UPSTREAM_BLOCKED`、`UPSTREAM_CHANGED`、`AUTH_REQUIRED`。

### 7.12 companies.list

- 鉴权：Bearer。
- 请求：`queryId`（必填）、`page`（默认 1）、`pageSize`（默认 20）、`fetchPages`（0–5，默认 0）、`refresh`。

## 12. SQLite 缓存 schema（草案）

```sql
CREATE TABLE IF NOT EXISTS queries (
  query_id TEXT PRIMARY KEY,
  cache_key TEXT UNIQUE,
  keyword TEXT NOT NULL,
  city_code TEXT NOT NULL,
  city_name TEXT,
  order_by INTEGER NOT NULL DEFAULT 4,
  page_size INTEGER NOT NULL DEFAULT 20,
  pages_fetched INTEGER NOT NULL DEFAULT 0,
  has_more INTEGER NOT NULL DEFAULT 0,
  anonymous INTEGER NOT NULL DEFAULT 0,
  fetched_at INTEGER NOT NULL,
  expires_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS jobs (
  query_id TEXT NOT NULL,
  page INTEGER NOT NULL,
  position INTEGER NOT NULL,
  position_number TEXT NOT NULL,
  json TEXT NOT NULL,
  fetched_at INTEGER NOT NULL,
  PRIMARY KEY (query_id, page, position_number)
);
CREATE INDEX IF NOT EXISTS idx_jobs_query ON jobs(query_id, page, position);
CREATE INDEX IF NOT EXISTS idx_jobs_number ON jobs(position_number);

CREATE TABLE IF NOT EXISTS job_details (
  position_number TEXT PRIMARY KEY,
  json TEXT NOT NULL,
  fetched_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS companies (
  company_number TEXT PRIMARY KEY,
  json TEXT NOT NULL,
  fetched_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS company_details (
  company_number TEXT PRIMARY KEY,
  json TEXT NOT NULL,
  fetched_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS company_jobs (
  company_number TEXT PRIMARY KEY,
  json TEXT NOT NULL,
  fetched_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS meta (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL,
  updated_at INTEGER NOT NULL
);
```

- 只存结构化 JSON；不存 raw 响应/HTML。
- 所有时间为 epoch ms；`expires_at` 用于 `cache clear --expired`。
- WAL 模式；单写者；启动时执行 schema 迁移。

## 16. 已知限制 / 下一步

1. **匿名限制**：未登录只能搜 1 页 20 条；登录后翻页上限待实测。
2. **EdgeOne 不可完全避免**：`/jobdetail` 页面直访首次会被拦截；优先 API，必须页面时中继/自动点击。
3. **数美设备指纹**：同一 profile 稳定使用，不伪造、不频繁更换。
4. **招聘者信息**：匿名字段有限，登录后更全（待实测）。
5. **暂无职位发布时间之外的时效字段**：用 `publishTime` + `firstSeenAt/lastSeenAt`。
6. **公司全职位页可能截断**：`companies.jobs.truncated` 标识。
7. **高级筛选**：v1 不做；字典已实测（`search/base/data`）。
8. **微信扫码/密码登录**：接口预留，v1 不承诺。
9. **多账号**：v1 单账号；架构预留（独立 profile/端口/cache）。
