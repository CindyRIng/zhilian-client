# 图片素材

| 文件 | 用途 | 来源 |
| --- | --- | --- |
| `hero-banner.jpg` | README 顶部横幅 | MiniMax-H3-Image 生成（无文字，避免文字渲染失真） |
| `logo.jpg` | 项目 Logo / 文档标识 | MiniMax-H3-Image 生成 |
| `architecture-illustration.jpg` | 架构章节概念图（精确架构以 Mermaid 为准） | MiniMax-H3-Image 生成 |
| `social-preview.jpg` | 文档封面 / 社交预览（1280×640） | MiniMax-H3-Image 生成 |
| `rest-docs.png` | REST 文档页截图 `http://127.0.0.1:8791/docs` | 真实运行截图（v0.1.1，1440×900） |

- 生成时遵循 `h3-image-prompt-writing` 技能：只描述可见画面、不要求模型渲染文字/Logo/品牌名，避免文字乱码。
- 图标与插画为装饰性素材；接口/架构事实以文档与 `spec/` 为准。
